02 —

Why this PE matters for H3

H3 rewards structured timing, audible dialogue, and camera intent — casual prompts often underspecify them.

Expand ≠ generate

The harness returns validated prompts. Loading MiniMax-H3 or calling an API is optional and separate.

Validated H3 dialect

Shot timelines, language-tagged dialogue, natural-English camera, and continuity checks against public skill grammar.

Deterministic repair

Schema validation plus bounded repair cycles — not ad-hoc prompt string surgery.

Honest evaluation

RAW vs PE demos use the same seed. Where PE is weaker, this page says so.

Scope note

Omni-Rewriter does not claim to reproduce private MiniMax Context-IR internals. The H3 profile encodes publicly documented prompt conventions and repository tests.
